# 供具体仓库合并的引用入口

将下面代码块正文**合并**进目标仓库已有AGENTS.md；没有AGENTS.md时仅在用户授权写入该仓库后创建。保留原有项目规则，不覆盖文件。这个模板不是自动部署到其他仓库的脚本。

```markdown
## 账号统一交付标准

开始修改、提交或上传前，读取：
https://github.com/qixian771-spec/.github/blob/main/AI_DELIVERY_STANDARD.md

按方案 → 拆解任务 → 任务卡 → 执行 → 测试 → 验收 → 提交完成本次适用工作。
每个里程碑与整体都有验收证据。发现缺项，先在已授权范围内补全；缺关键输入、权限或无法安全验证时停止依赖步骤并报告部分完成。
严禁自动兜底、吞异常、忽略失败、擅自重试/回滚或扩大范围。未执行检查写明原因，不拿模拟结果替代真实验收。
遵守用户当前约束及本仓库具体规则；统一标准不授予额外写入/发布权限。最终回复用内联表格或Mermaid。
若禁止联网，只使用本仓库已核验的标准副本及版本；没有副本则说明尚未读取，请用户提供内容，不假装已遵守。
```

支持AGENTS的工具才可能自动发现此入口；其他AI需要在任务提示中显式要求读取。中央仓库的AGENTS本身不会跨仓库自动生效。
